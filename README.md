# 단원 설계 도우미 · Lesson Studio v3.1

개념 기반 탐구(CBIL)와 학습과학에 기반하여 2022 개정 교육과정의 단원 설계를 한 단계씩 안내합니다. AI 제안을 교사가 선택·수정하거나 직접 작성할 수 있습니다.

**[앱 열기](https://knightayj52.github.io/Lesson-Design/)**

## 시작하기

1. 예시 단원을 둘러보거나 **새 단원 설계하기**를 누릅니다.
2. 학년군·교과를 선택하고 성취기준을 코드 또는 키워드로 찾습니다. 교과를 바꾸어 여러 기준을 함께 담을 수 있습니다.
3. 총 차시, 차시당 시간, 학급 여건을 입력하면 AI 제안과 검토에 반영됩니다.
4. 성취기준 → 개념 추출 → 일반화 → 탐구 질문 → 수행평가 → 수업 흐름 → 활동 전략 → 검토·완성 순으로 설계합니다.
5. 수업 흐름 단계에서 탐구 구간별 차시를 배분하고, 검토 단계에서 일반화·질문·활동의 연결을 확인합니다.
6. 완성한 설계는 워드(.docx)로 내려받거나 인쇄 화면에서 PDF로 저장합니다.

## AI 연결과 직접 작성

상단 **AI 연결**에서 본인의 Google AI Studio API 키를 등록합니다. 키는 제작자 서버에 저장하지 않으며 이 브라우저에 저장되고 Google API 인증에 사용됩니다. AI 요청 시 설계에 입력한 내용도 Google로 전송됩니다. 공용 기기에서는 사용 후 키를 삭제해 주세요. 사용 한도·비용은 Google 계정과 API 설정에 따라 달라집니다.

AI 연결이 없거나 요청이 실패해도 직접 입력으로 이어갈 수 있습니다. 오류 화면의 **AI 다시 요청**으로 재시도할 수 있습니다. AI 점검은 참고 의견이며, 미평가 항목과 평가 정합성은 교사가 확인해야 합니다.

## 저장과 백업

- 확정한 설계뿐 아니라 선택 중인 후보, 성찰 초안, 입력 중인 텍스트도 브라우저에 자동 저장합니다.
- **내 단원**에서 여러 설계를 관리합니다. 새 단원을 시작해도 이전 단원은 보관함에 남습니다.
- **단원 백업**으로 JSON 파일을 내려받고 **백업 불러오기**로 새 단원에 복원할 수 있습니다. API 키는 백업에 포함되지 않습니다.
- 브라우저 데이터 삭제나 다른 기기 사용에 대비해 백업을 보관하세요. 기기 간 자동 동기화는 제공하지 않습니다.
- 교사 성찰은 브라우저와 단원 백업에 보관하며, 공유용 워드·PDF에는 포함하지 않습니다.

## 개발

별도 빌드 없이 GitHub Pages에서 실행하는 정적 앱입니다.

- `index.html`: 화면 구조
- `styles.css`, `studio.css`: 기본 스타일과 반응형 화면
- `designer.js`: 설계 상태·저장·사용자 흐름
- `app.js`: 교육과정 데이터·Gemini 요청·문서 내보내기
- `data/`: 성취기준·핵심 아이디어·전략 자료

로컬 실행: `python -m http.server 8765`

회귀 검증: `node tests/regression.cjs` (외부 요청·API 키 없이 실행)
